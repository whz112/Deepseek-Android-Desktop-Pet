# 🎬 绿幕视频素材自动化处理流水线

一套完整的绿幕角色动画处理工具 —— 从原始 MP4 录制素材，到最终带透明背景、尺寸统一、适合网页播放的 WebM 缩略图。  
同时附带高级后期处理模块，支持光流插帧、循环平滑、亮度对齐等专业功能。

---

## 📝 生成原始视频的提示词参考

本流水线的输入是 **绿幕背景的 MP4 视频**。你可以使用 AI 视频生成工具（如豆包、Runway、Pika 等）依据以下提示词生成原始素材，确保角色动作规范、背景干净，便于后续自动抠像。

### 🎯 全局固定规则（必须遵守）

- 背景为单一纯色块（推荐绿色 #00FF00），**无任何阴影、杂物、渐变或边框**。
- 人物位置与大小全程固定：
  - 不允许 X 轴（左右）平移；
  - Y 轴仅允许原地起伏（无坐下等大幅下沉）；
  - 身体重心始终处于画面绝对中心垂直线，严禁左右漂移。
- 必须以**标准正面图**为第一起始帧，并在视频最后一秒（第10秒结束时）彻底恢复至与该帧完全一致的标准姿态。
- 人物头部和脚底均在画幅安全区内，全程居中，不漂移。**绝对禁止**任何物体超出画幅边缘、触碰底边或被裁剪。
- 头部左右转动时，肩膀和身体保持静止，仅颈部带动头部轻微旋转，头顶和下巴始终在安全区内。

### 📖 动作概述（示例：Q版蓝发女仆）

Q版蓝发女仆从围裙兜内取出一个蓝框的放大镜，将其缓缓举至右眼前方约一拳距离，透过镜片做出认真端详的姿势；随后头部轻轻向左、向右各转动一次（幅度约 15°），模拟观察周围细节；最后放下放大镜，将其放回兜内，恢复标准正面站立姿态。全程动作优雅缓慢，无跳跃或位移。

### ⏱️ 按秒分割画面（总时长 10 秒）

| 时间段 | 动作描述 |
|--------|----------|
| 0~2.5s | 标准正面站立，双手自然垂于身侧。目光微微下移，右手抬起探入围裙右侧的白色荷叶边兜内，指尖捏住放大镜手柄，开始向外抽出。 |
| 2.5~4.5s | 右手将放大镜完全抽出，平稳举至胸前高度，镜面朝前，眼神跟随镜片移动。 |
| 4.5~6.5s | 继续上抬，将放大镜轻轻置于右眼前方（距离眼睛约 15cm），镜片略微倾斜对准视线。身体不动，双眼自然睁开，仿佛透过放大镜仔细观察。 |
| 6.5~8.0s | 头部（以颈关节为轴）缓慢向左转动约 15°，停留 0.3s；再缓慢向右转动约 15°，停留 0.3s；然后回到正中。转动时肩膀和躯干保持静止，双手稳定握住放大镜。 |
| 8.0~9.0s | 将放大镜从眼前缓缓移开，垂直下落至胸前，右手握着手柄将其重新塞回围裙兜内，手部完全没入兜中后抽出，轻轻抚平兜口。 |
| 9.0~10s | 双手自然垂落于身体两侧，头部摆正，表情恢复平静，身体无偏移。第 10 秒结束时，全身姿态与起始标准正面图完全一致（包括发梢、裙摆褶皱均回归原位）。 |

> 你可以将此提示词直接发给 AI 视频生成工具，生成符合要求的绿幕 MP4，然后放入 `video/` 目录进行后续处理。

## ✨ 流水线特性

- **绿幕抠像**：自动采样绿色背景，生成 Alpha 通道，支持边缘羽化、白色描边和色溢去除
- **自动裁剪**：去除拍摄时左右两侧的固定黑边
- **角色尺寸归一化**：等比缩放、水平居中、脚底对齐到统一画布（可选）
- **批量编码**：输出低码率正方形 WebM，适合网页预览或缩略图
- **后期精加工工具集**：
  - 基于光流的首尾插帧，实现无缝循环
  - 双向亮度平滑，消除循环切换时的闪烁
  - 非待机动作向前对齐到待机动画的亮度与姿态（避免动作切换时的跳变）
  - 辅助工具：抽帧、时长探测、边缘透明化与水平位移修正

## 🔧 主处理流程（`main.py`）

主控脚本会按顺序调用以下模块，并在执行前自动清空中间目录（保留 `video/` 原始文件）。

1. **裁剪（`crop_step01.py`）**  
   使用 ffmpeg 裁剪左右各 235 像素，去除绿幕边缘的固定杂色/黑边，输出到 `step01/`。

2. **生成蒙版（`mask.py`）**  
   从 `step01/` 读取视频，自动采样画面边框的绿色，确定 HSV 基准，逐帧生成二值蒙版（前景白，背景黑），并进行形态学开闭运算去噪，输出灰度 MP4 到 `masks/`。

3. **去绿幕 + 羽化 + 描边（`chroma_step02.py`）**  
   结合 `step01/` 的视频和 `masks/` 的蒙版，对每一帧进行：
   - HSV 阈值提取绿幕区域
   - 边缘收缩（侵蚀），减少绿色溢出
   - 删除暗绿与特定 RGB 残留色块
   - 羽化（高斯模糊 Alpha 通道）
   - 可选白色外描边（半透明）
   输出透明 WebM（VP9 + yuva420p）到 `step02/`。

4. **尺寸归一化（`normalize_step03.py`）—— 可选**  
   从 `step02/` 读取透明视频，扫描首尾站立姿态的边界框，计算角色高度、脚底坐标和水平中心。然后将每一帧等比缩放到目标高度（如 900px），平移到 1200×1200 透明画布上（水平居中，脚底对齐到距底 100px）。  
   > 若视频中没有明显的站立姿态，此步骤可能计算不准，因此主流程会询问用户是否跳过。

5. **编码播放缩略图（`encode_thumbs.py`）**  
   从 `step03/`（或跳过时从 `step02/`）读取，缩放到用户指定的正方形尺寸（如 400×400），强制设定帧率（如 24 fps），使用 VP9 高压缩编码（CRF=40），输出到 `step04/`。

## 🔬 后期精加工（`material processing/`）

该目录包含面向高级用户的视频后处理工具，用于优化循环动画和动作切换。

### 第一层：基础 IO 转换
- `webm2png.py`：将 WebM 拆解为带 Alpha 通道的 PNG 序列（强制使用 VP9 解码器以正确读取透明通道）
- `png2webm.py`：将 PNG 序列合成为 WebM（VP9 编码，`yuva420p` 像素格式）

### 第二层：核心算法（光流与亮度处理）
- `insert_frame.py`：基于 Farneback 稠密光流，在首尾帧之间插入 N 张过渡帧（不含首尾本身），实现无缝循环
- `smooth.py`：对序列首尾各 N 帧进行双向亮度混合，并在边界插入光流过渡帧（对称处理）
- `smooth2.py`：前向亮度对齐——使用用户指定的外部尾帧（如待机动图的尾帧）作为亮度基准，将序列前 N 帧通过光流变形和亮度缩放强行对齐到目标，并在第 N 帧与第 N+1 帧之间插入光流过渡帧。用于让非待机动作的开头向待机动画靠拢，避免切换时画面闪烁。

### 第三层：业务流水线（一键脚本）
- `idle_smooth.py`：纯循环流水线（`webm2png` → `insert_frame` → `png2webm`），适用于自身首尾亮度一致的待机动图，使其无限循环不卡顿。
- `others_smooth.py`：亮度对齐 + 循环流水线（`webm2png` → `smooth2` → `insert_frame` → `png2webm`），用于非待机动作，先借用待机动图的色调统一亮度，再实现自身无缝循环。

### 第四层：辅助调试工具
- `extract_frame.py`：从任意视频中抽取指定索引的单帧，保存为 JPG/PNG，常用于挑选用作亮度基准的“尾帧图片”。
- `print_video_len.py`：遍历 `output/` 目录，用 ffprobe 精确打印所有视频时长（毫秒/秒/分钟），适用于 Android 项目动画注册。
- `clearEdge&offset.py`：将视频左右指定宽度的像素 Alpha 设为 0（去除边缘脏边/水印），并支持画面整体水平位移（正数右移，负数左移），空缺处自动填充透明。
